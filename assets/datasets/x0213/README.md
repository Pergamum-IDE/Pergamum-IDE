# x0213 reference data

This directory contains a generated JSON mapping table derived from public reference data published by x0213.org.

The JSON maps JIS X 0213 men-ku-ten codes to Unicode strings.

Original source:

- x0213.org

Notes:

- The mapping table is used for Aozora Bunko gaiji replacement.
- The JSON file was converted into a format suitable for Pergamum.
- This data is treated as factual character mapping data.
