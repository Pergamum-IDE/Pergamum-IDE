# ADR-0015: フォント指定とフォント解決

- ステータス: Accepted
- 日付: 2026-09-16

## コンテキスト

Pergamum はアプリ UI・エディタ・プレビューの3箇所でユーザーがフォントを選択できるようにする。フォント設定はアプリ設定とプロジェクト設定の双方に存在し、プロジェクト設定は `.pergamum` と同じ場所に保存されるため、プロジェクトとともに別のマシンへ移動する。インストール済みフォントはマシンごとに異なり、同一フォントでもファミリー名が OS によって異なる場合がある。

CSS はフォントが存在しない場合に自動でフォールバックし、その事実を通知しない。字形単位の代替（異体字セレクタ非対応など）はソーステキストを変更しないが、表示上は別の字として現れる。

フォントの列挙には Chromium の `window.queryLocalFonts()` を用いる。この API はユーザー操作を起点としなければ呼び出せない。

Pergamum は日本語以外の文字体系（ハングル、簡体字、繁体字ほか）を利用するユーザーを排除しない。

## 決定

### スロットと設定値

- **F-1** フォントスロットは「アプリ UI」「エディタ」「プレビュー」の3つとする。
- **F-2** 各スロットの値は、ファミリー単位のフォントを要素とする順序付きリストとする。ウェイト・スタイル単位（フェイス）の選択は提供しない。
- **F-3** リストの各要素は、CSS に渡すファミリー名と、選択時の UI 言語での表示名の組として保存する。カンマ区切りの文字列としては保存しない。
- **F-4** リストの要素はすべて必須とする。リストは欧文用・和文用などの組み合わせを表現するものであり、代替候補の列ではない。
- **F-5** フォント設定はアプリ設定を既定値とし、プロジェクト設定で上書きする。
- **F-6** CSS の `font-family` は、リストの要素を順に並べ、末尾にスロットごとに定めた総称ファミリーを付加して生成する。総称ファミリーはユーザーの設定値に含めない。
- **F-7** エディタは太字・斜体を用いない。
- **F-8** `font-synthesis` は全スロットで既定値とする。
- **F-9** 全スロットの `lang` 属性は、アプリ設定の UI 言語とする。

### フォントキャッシュ

- **F-10** `queryLocalFonts()` はユーザー操作を起点としてのみ呼び出す。
- **F-11** 列挙結果はファミリー単位のフォントキャッシュとして userData 配下に保存する。フォントキャッシュはマシン固有の情報であり、プロジェクトに含めない。
- **F-12** フォントキャッシュは各ファミリーについて、CSS に渡すファミリー名、表示名、固定幅属性（F-23）を保持する。
- **F-13** Pergamum は文字体系ごとの収録判定（欧文を持つか、和文を持つか等）を行わない。
- **F-14** CSS に渡すファミリー名には、`queryLocalFonts()` が返す `FontData.family` をそのまま用いる。
- **F-15** 表示名はフォントファイルの `name` テーブルから取得する。同一ファミリーに属する全フェイスを対象に、次の順で最初に得られた値を用いる。
  1. UI 言語の nameID 16
  2. `family` と英語の nameID 1 が一致するフェイスの、UI 言語の nameID 1
  3. `family`
- **F-16** 表示名およびファミリー名は、フォントが収録する表記のまま保持し、正規化しない。照合は完全一致で行う。
- **F-17** `FontData.fullName` は使用しない。
- **F-18** Regular（ウェイト 400 の非斜体フェイス）を持たないファミリーも一覧から除外しない。

### 照合と通知

- **F-19** アプリ起動時およびプロジェクトを開いた時に、有効なフォント設定の各要素をフォントキャッシュと照合する。照合は CSS に渡すファミリー名、表示名の順で行い、一致したキャッシュ項目のファミリー名を CSS に渡す。
- **F-20** 照合結果は次の3状態とする。
  - **未スキャン**: フォントキャッシュが存在しない。フォント情報が未取得であることを案内し、不在の警告は出さない。
  - **キャッシュ上で不在**: いずれかの要素がキャッシュに存在しない。不在の要素を名指しした通知トーストを出し、トーストに再スキャン操作を含める。
  - **再スキャン後も不在**: 再スキャン後もいずれかの要素が存在しない。不在を確定し、代替表示中であることを UI 上に示す。
- **F-21** 照合結果にかかわらず、Pergamum はフォント設定値を変更しない。
- **F-22** 字形単位の代替表示は検出の対象外とする。フォント指定ダイアログに「フォントによっては異体字などが正しく表示されない場合があります」と表示する。

### 固定幅判定

- **F-23** 固定幅フォントとは、次の2条件をともに満たすフォントをいう。
  - `W` と `i` の送り幅が等しい。
  - `W` 2文字分と `Ｗ`（U+FF37）の送り幅が等しい。
- **F-24** 判定は Canvas の `measureText` による実測で行う。各測定文字について、総称ファミリーを変えた2通りの指定で幅が一致することを確認し、対象フォント自身の字形で測定されていることを保証する。
- **F-25** 複数要素のリストについては、リスト全体を指定した状態で F-23 の判定を行い、結果をダイアログに表示する。
- **F-26** フォント指定ダイアログは「固定幅フォントのみ」のスイッチを持つ。スイッチの既定値は OFF とする。エディタスロットを固定幅フォントに限定しない。

### フォント指定ダイアログの見本

- **F-27** ダイアログはユーザーが編集できる見本欄を持つ。初期値は UI 言語ごとに i18n リソースで定義する。
- **F-28** 見本欄の編集内容は保存しない。
- **F-29** ダイアログのフォント一覧と見本欄は、各スロットの本文と同じ `font-weight: 400` で描画する。Regular を持たないファミリーの実際の見た目は、選択前にこの描画で示す。

## 帰結

- 別のマシンでプロジェクトを開いた場合、不在のフォントはユーザーに通知され、設定値は保持される。元のマシンに戻れば同じ表示が得られる。
- フォントキャッシュが古い場合も、ユーザーは通知トーストから1操作で再スキャンできる。
- 文字体系ごとの判定を行わないため、「使われない要素」の検出や並び順の警告は提供しない。並び順の妥当性はユーザーが見本欄で確認する。
- 固定幅判定は全角文字として `Ｗ` のみを測定するため、ハングル等の幅が全角と揃っているかは保証しない。
- 字形単位の代替表示は通知されない。
- ファミリーの集約は Chromium が行うため、Pergamum はウェイト違いのフェイスを自前で束ねない。表示名の取得のために `name` テーブルのパーサーを保持する。
- 単一ウェイトのみで構成されるファミリー（BIZ UD明朝、HG明朝B 等）も選択できる。
- リストの要素が収録しない文字は、`lang` 属性に基づき Chromium が選んだフォントで描画される。UI 言語と原稿の言語が異なり、かつ原稿の文字を収録するフォントをリストに含めない場合、字形が原稿の言語と一致しないことがある。

## 範囲外

- ウェイトの選択 UI
- 字形単位の代替表示の検出（DevTools Protocol による診断を含む）
- 文字体系ごとの収録判定
- 見本欄の内容の永続化
- UI 言語とは独立した原稿の言語設定
